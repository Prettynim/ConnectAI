## 🚀 최종 출력 포맷 및 파일 형식 정의 (Output Format & File Specification)

웹사이트(미학적 매력 + 실용적 효율성)와 소셜 미디어 콘텐츠(후크 중심)의 목표에 맞춰, 품질과 압축률을 모두 고려한 표준화된 포맷을 정의합니다.

### 1. 웹사이트/디자인 자산 (Website/Design Assets)

| 자산 유형 | 권장 파일 형식 | 해상도/특징 | 용도 및 이유 |
| :--- | :--- | :--- | :--- |
| **메인 비주얼 (Hero Images)** | **WebP** 또는 **AVIF** | 1920px (가로) 이상, 적절한 압축률 유지 | 웹 로딩 속도 최적화. 고품질을 유지하면서 파일 크기를 최소화하여 UX를 개선합니다. |
| **아이콘 및 UI 요소** | **SVG** | 벡터 기반, 해상도 독립적 | 모든 디바이스에서 완벽하게 선명하며 확대/축소에 무한대로 대응 가능하여 '미학적 매력'을 극대화합니다. |
| **폰트 및 로고** | **SVG / Web Font (.woff2)** | 벡터 또는 압축된 웹 폰트 포맷 | 브랜드 정체성(Typography System)의 일관성을 보장합니다. |

### 2. 비디오/숏폼 콘텐츠 (Video/Short-form Content)

| 자산 유형 | 권장 파일 형식 | 해상도/특징 | 용도 및 이유 |
| :--- | :--- | :--- | :--- |
| **유튜브/롱폼 영상** | **MP4 (H.264 코덱)** | 1920x1080 또는 3840x2160 (4K) | 범용성과 압축 효율성 측면에서 가장 안정적이며, 고품질을 보장합니다. |
| **YouTube Shorts/Reels** | **MP4 (H.264 코덱)** | 1080x1920 (세로형) | 모바일 환경에 최적화된 세로 포맷으로, 플랫폼별 권장 해상도를 준수합니다. |
| **썸네일 이미지** | **PNG / JPG** | 1280x720 (권장) | 클릭률(CTR)을 높이는 시각적 후크를 제공하며, 명확한 메시지를 전달해야 합니다. |

## ⚙️ 자동화된 렌더링 파이프라인 구축 방안 (Automated Rendering Pipeline)

수동 작업을 최소화하고 'Filter First, Visual Hook Dominance' 원칙을 시스템적으로 적용하기 위해 **CI/CD 및 워크플로우 기반의 자동화 파이프라인**을 구축합니다.

### 1단계: 콘텐츠 생성 및 관리 (Source & Asset Management)

*   **도구:** Notion/Airtable (프로젝트/KPI 관리), Google Drive/S3 (원본 파일 저장소).
*   **자동화:** 모든 디자인 브리프, 카피라이팅 초안(Writer 산출물), 데이터 리서치 결과는 중앙 저장소에 기록되어야 하며, 이들이 자동으로 다음 단계의 입력값으로 사용되도록 구조화합니다.

### 2단계: 비디오/이미지 자동 렌더링 (Automated Rendering)

이 단계에서는 **AI 기반 편집 및 배치 자동화**를 목표로 합니다.

*   **목표:** 스크립트(Writer 산출물)와 디자인 가이드라인(Designer 산출물)을 입력하면, 최소한의 수동 개입으로 최종 숏폼 콘텐츠 초안을 생성합니다.
*   **기술 스택 제안 (MVP):** Python 기반 자동화 스크립트 (`MoviePy`, `Pillow`)를 사용하여, 정의된 시간 프레임에 맞춰 자막 배치 및 핵심 비주얼(Designer의 컬러 팔레트 적용)을 자동으로 삽입하는 템플릿을 구축합니다.
*   **API 통합:** 최종적으로 생성된 결과물은 클라우드 스토리지(AWS S3/Google Cloud Storage)에 **메타데이터와 함께 자동 업로드**되도록 설정합니다.

### 3단계: 배포 및 최적화 (Deployment & Optimization)

*   **도구:** Zapier/Make (워크플로우 연동), Custom API Script.
*   **자동화:**
    1.  렌더링 완료 시, 자동으로 **썸네일 생성 스크립트** 실행 (핵심 메시지 강조).
    2.  최적화된 MP4 파일을 각 플랫폼(YouTube, Instagram)별 권장 해상도에 맞게 **자동 리사이징 및 압축** 후 업로드 API를 호출합니다.
    3.  웹사이트 업데이트 시, 새로운 비주얼 자산이 자동으로 CMS(Content Management System)에 반영되도록 연동합니다.

### 🎯 핵심 자동화 요약 (Automation Summary)

| 프로세스 | 수동 작업 최소화 목표 | 핵심 기술 요소 |
| :--- | :--- | :--- |
| **기획 → 디자인** | 리서치 데이터와 브랜드 가이드라인의 일관성 유지 | Notion/Airtable 기반 구조화된 프롬프트 체인 |
| **편집 → 출력** | 수동 자막 및 배치 작업 제거 | Python (MoviePy) + 템플릿 엔진 |
| **배포 → 최적화** | 플랫폼별 포맷 변환 및 업로드 반복 작업 제거 | API 연동 (S3, YouTube API) + Make/Zapier 워크플로우 |

## ❓ 영상 제작에 사용되는 주요 툴 (Video Production Tools)

영상 콘텐츠를 제작하는 데는 목적과 예산에 따라 다양한 도구가 존재합니다. 자동화 파이프라인을 구축할 때는 **'AI 기반의 자동 편집'** 기능이 통합된 도구를 우선 고려해야 합니다.

### 1. 전문 소프트웨어 (High Control & Quality)

*   **Adobe Premiere Pro / DaVinci Resolve:** 전문가 수준의 세밀한 편집, 색 보정(Color Grading), 사운드 디자인을 원하는 경우 사용합니다. (→ **개발자의 자동화 스크립트가 이들의 API를 호출하여 렌더링을 트리거하는 역할**)

### 2. AI 기반 자동 편집 및 생성 도구 (Automation & Speed)

*   **Descript:** 텍스트 기반으로 영상 편집이 가능하여, 스크립트를 수정하면 영상 전체가 동기화되어 편집되므로 대본 기반의 콘텐츠 제작에 매우 효율적입니다.
*   **Runway / Pika Labs (Text-to-Video):** 텍스트 프롬프트를 입력하여 짧은 클립을 생성하는 데 사용됩니다. 이는 '후크' 장면이나 미학적 배경 이미지를 빠르게 프로토타이핑할 때 유용합니다.

### 3. 모션 그래픽 및 템플릿 (Branding Consistency)

*   **Canva Pro:** 비록 영상 편집 자체는 전문 툴이 아니지만, 정의된 브랜드 컬러 팔레트와 타이포그래피 시스템(Bebas Neue, Inter)을 적용하여 고품질의 **정적인 썸네일 및 인트로/아웃트로 디자인**을 빠르게 생성하는 데 필수적입니다.

### 💡 최종 권고 (Recommendation)

자동화 파이프라인을 구축하는 단계에서는 **Python 스크립트(MoviePy)**를 핵심 엔진으로 사용하되, 최종 결과물의 미학적 완성도를 위해 **DaVinci Resolve**의 렌더링 결과를 활용하거나, **Canva**로 디자인 자산의 일관성을 검증하는 하이브리드 접근법을 권장합니다.
