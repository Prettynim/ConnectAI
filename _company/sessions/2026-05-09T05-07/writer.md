# 웹사이트 개발자 전달용 최종 작업 Prompt

본 문서는 **'Filter First, Visual Hook Dominance'** 원칙을 기반으로 사용자 경험(UX)과 전환율(CRO) 극대화를 목표로 하는 웹사이트 리뉴얼 및 개발을 위한 구체적인 지침입니다. 이 프롬프트는 개발팀이 디자인 의도를 정확히 구현하여 최종 목표인 **월 수익 500만원 달성**에 기여할 수 있도록 작성되었습니다.

## 1. 프로젝트 비전 및 핵심 목표 (Vision & Goal)

**최종 목표:** 사용자 탐색 마찰을 제거하고 시각적 매력을 극대화하여, 방문자가 의도한 정보를 최소의 노력으로 찾고 구매/구독 행동(Action)을 취하도록 유도한다.

**핵심 원칙:**
1.  **Filter First (탐색 효율성):** 사용자가 원하는 정보를 찾는 과정을 가장 빠르고 쉽게 만들어야 한다.
2.  **Visual Hook Dominance (시각적 몰입도):** 미학적 요소와 강력한 후크를 통해 제품의 지각된 가치를 높여 프리미엄 경험을 제공한다.

## 2. 구조 및 사용자 흐름 설계 (Structure & User Flow Blueprint)

### A. 메인 페이지 (Homepage) 전략
*   **최상단:** 브랜드 로고 및 명확한 내비게이션 바(Navigation Bar).
*   **Hero Section:** 가장 강력하고 매력적인 'Visual Hook' 콘텐츠와 핵심 가치(시간 절약, 전문성)를 시각적으로 전달하는 섹션 배치. (디자이너가 확정한 컬러 팔레트 및 타이포그래피 적용 필수.)
*   **핵심 기능 영역:** **필터링 시스템을 최우선으로 노출**하며, 사용자가 카테고리를 선택하고 즉시 결과를 볼 수 있는 인터페이스를 중앙에 배치한다. (Filter First 원칙 적용)
*   **콘텐츠 피드:** 필터를 통해 걸러진 결과 목록을 미학적으로 구성하여 시각적 매력을 극대화한다.

### B. 콘텐츠 페이지 전략 (Category/Listing Pages)
*   **필터 우선 구조:** 모든 목록 페이지는 좌측 사이드바 또는 상단에 **모든 핵심 필터(카테고리, 속성 등)**를 고정 배치하여 사용자가 즉시 탐색할 수 있도록 한다.
*   **정보 계층화:** 세부 정보는 명확한 계층 구조(예: 레트로 게임 > 생산성 > 세팅 방법)로 구성하여, 사용자가 깊이 있는 정보를 체계적으로 탐색하도록 돕는다.
*   **시각적 강조:** 각 제품/콘텐츠 카드에는 강력한 시각적 후크를 적용하며, 정보의 밀도를 조절하여 시각적 집중을 유도한다.

## 3. 기능 및 인터페이스 요구사항 (Functionality & UI Requirements)

### A. 필터링 시스템 (Filtering System - **Filter First Implementation**)
*   **다중 필터 지원:** 사용자가 최소 3가지 이상의 기준으로 정보를 세분화할 수 있도록 필터 옵션을 설계한다.
*   **실시간 피드백:** 필터를 적용할 때 결과 목록이 즉각적으로 업데이트되어야 하며, 로딩 시간은 1초를 넘지 않도록 최적화한다.
*   **검색 기능 강화:** 강력한 검색 기능을 제공하고, 자동 완성(Autocomplete) 기능을 통해 사용자의 입력에 따라 관련 결과를 실시간으로 제안해야 한다.

### B. 시각적 디자인 시스템 (Visual Design System - **Visual Hook Implementation**)
*   **컬러 팔레트 준수:** 사전에 확정된 브랜드의 Primary/Secondary 컬러 팔레트를 모든 UI 요소(버튼, 링크, 배경)에 일관되게 적용한다.
*   **타이포그래피 계층:** H1, H2, 본문 텍스트 간의 크기, 굵기, 간격을 명확히 정의하여 정보의 위계를 시각적으로 구분한다.
*   **미학적 통일성:** 모든 콘텐츠 카드 및 섹션은 일관된 레이아웃과 여백(Whitespace) 규칙을 따르며, 미학적 완성도를 최우선으로 한다.
