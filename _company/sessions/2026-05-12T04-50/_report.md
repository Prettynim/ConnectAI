📱 영숙: 사장님, 유튜브 Data API 접근을 위한 Google OAuth 설정이 필요합니다. 😊

API를 연결하기 위해서는 사용자님의 계정 정보를 통해 인증 절차를 거쳐야 합니다.

원활한 연결을 위해 다음 정보들을 준비해 주시면 제가 설정을 도와드리겠습니다.

✅ **필요한 정보:**
1. **Client ID**
2. **Client Secret**
3. **Redirect URI** (리다이렉션 URI)

이 정보들을 준비하여 알려주시면, 시스템에 필요한 설정 정보를 제공할 준비를 하겠습니다. ⚙️

준비되시는 대로 말씀해주세요!
